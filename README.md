# wall_climb_force_compliance_robot

## Overview

ROS2 Humble demo package: Manipulator constant normal force compliance on planar wall, with bump adaptation & force-based E-Stop. Built on ROS2, Nav2, MoveIt2, Gazebo. Suitable for **facade inspection / cleaning / surface contact task prototype**.

#### Basic notes:

>A **FT (Force/Torque) sensor** in robotics and automation is a multi-axis measurement device—often mounted at a robot's wrist or end-of-arm tooling—that **detects forces and rotational moments (torques)** across six degrees of freedom (F_x, F_y, F_z, M_x, M_y, M_z).
