# \# wall\_climb\_force\_compliance\_robot



ROS2 Humble demo package: Manipulator constant normal force compliance on planar wall, with bump adaptation \& force-based E-Stop. Built on ROS2, Nav2, MoveIt2, Gazebo. Suitable for facade inspection / cleaning / surface contact task prototype.



\#### Basic notes:



>A FT (Force/Torque) sensor in robotics and automation is a multi-axis measurement device—often mounted at a robot's wrist or end-of-arm tooling—that \*\*detects forces and rotational moments (torques)\*\* across six degrees of freedom (F\_x, F\_y, F\_z, M\_x, M\_y, M\_z).
